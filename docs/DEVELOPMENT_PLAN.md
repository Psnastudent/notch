# Development Roadmap

1. **Phase 0 — Complete:** requirements, designs, risks, and environment assessment.
2. **Phase 1 — Next:** solution foundation, settings, lifecycle, single instance, and tests.
3. **Phase 2:** Island and dock visual foundation with DPI-aware positioning and hover behaviour.
4. **Phase 3:** pinned-app dock and safe application launching.
5. **Phase 4:** dynamic-island cards and interaction states.
6. **Phase 5:** event-driven or on-demand Windows integrations.
7. **Phase 6:** fullscreen detection, Gaming Mode, and measured performance work.
8. **Phases 7–10:** optional features, settings polish, QA, and release packaging.
