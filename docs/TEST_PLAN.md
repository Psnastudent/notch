# Test Plan

## Phase 1 unit tests

- Defaults are returned when the settings file is absent.
- Settings round-trip through atomic JSON persistence.
- Invalid JSON falls back safely and preserves recoverable evidence.
- Lifecycle starts modules in registration order and stops them in reverse order.
- A second single-instance acquisition is rejected.

## Later verification

- WPF hover and expansion behaviour, multi-monitor placement, DPI levels, media/session adapters, fullscreen detection, and resource measurements on Windows 10 22H2 and Windows 11.
